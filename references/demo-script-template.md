# Short Demo Script Template (about 2–3 minutes)

Use this outline for every major version. If the product cannot follow it cleanly, simplify first.

## 1. Start (about 15 seconds)

- Open the app / sign in
- Land on Home
- Briefly show the navigation and the main primary action(s)

## 2. Main daily task (60–90 seconds)

1. Start the most common task from Home (short path)
2. Complete it with clear, obvious steps
3. Return to Home and show the result in a widget or list

The path must feel obvious without training.
Repeat the same flow idea on a phone-sized viewport if the audience cares about mobile.

## 3. Personalization (20–30 seconds)

- Open widget settings or switch a preset
- Hide one widget or change the layout
- Show that Home updates immediately

## 4. Close (about 15 seconds)

- Note that advanced options exist but stay out of the way
- Emphasize speed, clarity, and modern feel compared with older tools

## Failure conditions

The demo fails if:
- The main task needs many steps or confusing menus
- The presenter must explain complicated navigation
- Personalization is missing or hard to find
- The layout feels broken or cramped on mobile
- The watcher looks confused at any step

If any failure condition is true, return to the UX-First Gate and simplify.
