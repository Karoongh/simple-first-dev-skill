# Modern UI Guidelines (current practice)

Use these as the default visual and interaction standard unless the project has a documented reason to differ.

## Layout and spacing

- Mobile-first: design the narrow screen first, then enhance for larger screens
- Consistent spacing scale (commonly 4 or 8 px base)
- Generous whitespace around groups of content — avoid dense “admin panel” packing
- Clear visual hierarchy: one primary focus per screen region

## Typography and contrast

- Readable body size and comfortable line length
- Strong contrast for text and important icons
- Limited type scale (a few sizes used consistently)
- Support RTL layouts when the product language requires it

## Color and surfaces

- Calm neutral background
- One clear accent color for primary actions
- Subtle borders or soft elevation instead of heavy boxes
- Status colors (success, warning, danger) used sparingly and consistently

## Components and interaction

- Primary buttons are visually dominant and easy to tap
- Touch targets large enough for fingers on phones
- Modals, bottom sheets, and drawers for focused tasks instead of new pages when possible
- Helpful empty states with a clear next action
- Fast feedback (loading indicators, success confirmation, inline errors)

## Motion

- Short, purposeful motion only
- Respect user preference for reduced motion
- Never block the user with long decorative animation

## Data density

- Prefer cards or progressive disclosure on small screens
- On large screens, tables are fine when they stay scannable and have clear actions
- Avoid showing every column and every control at once by default

## Accessibility basics

- Keyboard reachable interactive elements
- Visible focus states
- Meaningful labels for inputs and buttons
- Do not rely on color alone to convey meaning

## What “modern and user-friendly” means in practice

The product should feel:
- Calm rather than busy
- Fast rather than heavy
- Obvious rather than clever
- Comfortable on a phone in one hand
- Easy to demonstrate to a new customer in a few minutes
